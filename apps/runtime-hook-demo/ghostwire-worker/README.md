# Ghostwire obfuscated worker fixture

The HTML, worker, and build script are copied unchanged from [sofianeelhor/ghostwire](https://github.com/sofianeelhor/ghostwire/tree/c3377f8be59fc2b2f2a620bbae75714902b0c114/examples/obfuscated_app) at commit `c3377f8be59fc2b2f2a620bbae75714902b0c114` under its [MIT license](LICENSE). Files: `parcel.html`, `signer-worker.js`, and `build_worker.cjs`. The local Node server in `../lab.mjs` replaces the upstream Python server while preserving its synthetic receipt API. See the parent [demo guide](../README.md) to run and interpret it. `signer-worker.js` is the checked-in obfuscated output; rebuilding it requires the upstream JavaScript dependencies.
