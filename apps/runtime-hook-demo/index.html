What happens inside an anonymous function?

Paste a toy token. This page splits it, runs every character through an unnamed callback, and checks a tiny checksum. Stop inside that callback to inspect its inputs and the closure value it uses.

Honest comparison: Chrome DevTools can break here too. REB’s current advantage is selecting that callback from a cursor and collecting bounded entry/return hits in a disposable experiment page. Neither approach makes this a secure token system.

03 / BREAK INSIDE

The line to investigate

Open real demo.js ↗
Array.from(payload).map((character, index) => {
  const code = character.charCodeAt(0);
  const weighted = (code * (index + 1) + salt) % 97; ← select here
  return weighted;
});

The callback has no name and is created inside a closure. That makes global window.someFunction wrapping awkward, not ordinary source debugging impossible.

THE POINT

Two ways to watch the same call

BROWSER DEVTOOLS

Interactive breakpoint

Open Sources → demo.js, click the const weighted line, and process the token. The page pauses; inspect character, index, and salt, then resume.

Great for one call you inspect manually.
REB RUNTIME HOOKS · CDP TODAY

Bounded experiment hits

In Origin Trace’s isolated Experiment page, choose demo.js and a cursor on that same line. REB resolves the enclosing arrow function, arms entry/return breakpoints, records bounded hits, and resumes automatically.

Great for repeat calls and deliberate return experiments.

A future native/V8 probe would sit below CDP. This demo does not claim REB already has one. JavaScript hooks also do not reveal the internals of native browser code or WebAssembly by themselves.
