Synthetic document-start fixture

Not run.

This page defines window.syntheticTransform(text, rounds) in an inline script, then calls it. A document-start Console script runs before this inline script, so it can observe the definition as it happens.

The child frame is same-origin by default. Append ?child=http://127.0.0.1:8081/synthetic-transform-child.html to point it at a second local origin, which gives the child its own renderer process. Only an explicit http or https value is honored.

Append ?reuse=1 to add a second, script-created child frame. The page touches its initial empty document before pointing it at the same-origin child page, so Blink keeps that window and its script context for the child's new document.
