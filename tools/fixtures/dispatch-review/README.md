# Dispatch classification review inputs

Repository-owned copies of the small repro inputs from two independent reviews
of the dispatch classifier. Each is a short synthetic program written for the
review; none comes from a third-party module. The large, repetitive review
inputs are generated byte for byte by
`apps/origin-trace-backend/src/vm_review_inputs.rs` instead of being checked in.

The differential invariant test
(`classification_never_changes_tier_or_score_on_any_owned_input`) runs every
file here, every dispatch-shape fixture, the other repository JavaScript and
Wasm fixtures and the generated inputs, with and without the opcode-claim gate,
and requires equal tier and score.

| Prefix | Shape |
| --- | --- |
| `f*`, `p526_*` | first-review probes: statement-form do-while, `.call` routers, loop dispatch |
| `t*`, `v2*` | handler tables dispatched in nested functions, through temporaries, by `.call`/`.apply`, or not at all |
| `m*` | minified comma declarations and braceless loops |
| `n*` | normalized, guarded, defaulted and overwritten arguments |
| `r*` | rotated loops |
| `x*` | text scans, a graph walk, shadowed cursors and an arguments loop |
